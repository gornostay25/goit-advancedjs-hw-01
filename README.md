# GoIT Advanced JavaScript — Homework 9

Домашня робота: галерея зображень (SimpleLightbox) та форма зворотного зв’язку (localStorage).

## Запуск

```bash
bun install
bun run dev
```

- [http://localhost:5173](http://localhost:5173) — головна
- [http://localhost:5173/1-gallery.html](http://localhost:5173/1-gallery.html) — галерея
- [http://localhost:5173/2-form.html](http://localhost:5173/2-form.html) — форма

## Збірка

```bash
bun run build
```

Перед деплоєм на GitHub Pages оновіть `--base` у `package.json` на назву вашого репозиторію.
